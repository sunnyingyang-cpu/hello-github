最快路径：第一次提交与推送

  1. git init — 初始化仓库
  2. git add README.md — 加入暂存区
  3. git commit -m "first commit" — 提交快照
  4. git branch -M main — 主线改名 main
  5. git remote add origin <url> — 关联远程
  6. git push -u origin main — 推送到 GitHub
