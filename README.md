## 🎯 这个仓库的目标

作为面试作品集的一部分，我希望它最终能展示：

- 清晰的 **commit message** 习惯（每个提交都有明确意图）

- 良好的 **README / 文档** 编写能力
- 持续的、有节奏的提交记录（不是一次性的「初始化」仓库）

## 🛠 我常用的 Git 命令

```bash
git status               # 查看当前改动状态
git add .                # 把改动加入暂存区
git commit -m "说明"      # 提交一个版本快照
git push                 # 推送到 GitHub
git branch feature-x     # 新建分支
git switch feature-x     # 切换到分支
git merge feature-x      # 合并分支
git log --oneline        # 查看提交历史
```
